# Todo Dia

App estático (index.html, sw.js, manifest.json) publicado pelo GitHub Pages a partir da branch `main`.

## Publicação
- Toda alteração pedida deve ir direto para a `main` e ser enviada (`git push origin main`), para entrar no ar.
  Não deixar mudanças paradas em outra branch nem abrir PR, a menos que a dona do projeto peça.
- Ao mudar arquivos do app, aumentar a versão do cache em `sw.js` (`todo-dia-vN`).
